# The Business of Data

A graduate course on the financial, legal, and organizational decisions that
determine whether a model becomes a product. Taught by case study rather than
code.

Fourteen weeks. Each week pairs a 90-minute asynchronous module on one business
function with a 90-minute synchronous case discussion, in which four students
hold conflicting roles and account for a decision real managers made.

Site: https://johnsanterre.github.io/business-of-data/
